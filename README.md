# 跃迁 · 大学生成长实践平台

面向大学生的技能实践 Demo。目标是帮助零经验学生通过真实、边界清晰的小项目积累第一段可验证的实践经历，获得收入、作品、履约记录与下一次机会。

## 当前能力

- 三步建档：技能、联系方式、简介文件
- 岗位浏览、详细岗位信息、收藏与收藏夹
- 接单申请、重复申请拦截、动态订单状态筛选
- 成长值、任务、阶段、徽章与资料更新
- 移动端适配

## 本地运行

```powershell
python -m http.server 4174 --bind 127.0.0.1
```

在浏览器打开 `http://127.0.0.1:4174/`。

## 数据库

数据库结构位于 `database/schema.sql`。当前前端为纯静态 Demo，状态保存在浏览器 localStorage；连接腾讯云 MySQL 后，需要新增后端 API 替换本地状态存储。
